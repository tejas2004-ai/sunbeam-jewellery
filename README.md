# Sunbeam Jewellery — Modern Heirlooms

A modern luxury jewellery storefront and digital experience for **Sunbeam Jewellery**. Handcrafted fine jewellery, sculptural 18k gold-plated heirlooms, bespoke atelier commissions, and curated collections designed in India and worn worldwide.

## ✨ Features

- **Brand Wordmark & Visual Identity**: Prominent luxury editorial branding for SUNBEAM JEWELLERY in Playfair Display serif with warm amber gold accents.
- **Sticky Glassmorphic Navigation**: Seamless header with backdrop blur and responsive cart/search overlays.
- **Full-Screen Ticker & Marquee**: Continuous, full-screen infinite marquee banner passing edge-to-edge.
- **Curated Collections & Editorial Stories**: Visual lookbooks for statement earrings, gold rings, and bespoke heirlooms.
- **Luxury Atelier & Bespoke Showcase**: Digital showcase for private design consultations.
- **The Sunbeam Letter**: Redesigned champagne-silk VIP invitation section with perks pills and integrated subscription form.
- **Interactive Shopping Bag & Wishlist**: Dynamic cart count, quick-add drawer, and local storage state.

## 🚀 Getting Started

To view the website locally, open `index.html` in any modern web browser or serve it via a local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Then navigate to `http://localhost:3000`.

## 🛠 Tech Stack

- **HTML5**: Semantic, accessible structure
- **Vanilla CSS**: Custom design system, responsive typography, modern CSS grid & flexbox
- **Vanilla JavaScript**: Lightweight interactions, cart state management, search overlay, and animations
